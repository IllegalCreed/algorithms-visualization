## 背景

窄屏播放器把五个控制按钮放入五列 grid 后仍使用 `width: 100%`，按钮被拉成长椭圆，速度选择框也被网格列撑宽。用户反馈截图同时显示：空队列的固定车道在手机可视区域内被截断；计数/桶轨道换行后把最后一个桶单独放到下一行，破坏了桶之间的横向比较。

## 要做什么

- 播放器重置、上一步、播放、下一步、循环按钮保持 44×44 CSS px 触控方形，并在 grid 单元内居中。
- 播放速度选择框保持紧凑宽度，不随两列 grid 拉伸。
- 空队列和空双端队列在窄屏铺满当前可用宽度，空态提示居中且不被固定画布裁掉；非空车道继续保持稳定画布，并在组件内部横向滚动。
- `CountView` 与 `BucketView` 的桶列始终保持一行；窄屏超出时仅组件自身横向滚动，页面不产生横向溢出。
- 预渲染静态入口不得保留本地 preview 主机资源地址，双 base 产物中的脚本、样式和 modulepreload 必须指向站内资源。
- 中英文共用同一布局规则，不改变算法步骤、数据、按钮事件和桌面双栏布局。

## 不做什么

- 不改变任何算法 oracle、步骤序列、代码高亮、播放器状态机或桶数据。
- 不把所有窄屏可视化强行缩放到不可读的尺寸，也不增加页面级横向滚动。
- 不调整 Header、Docs 抽屉或服务器安全配置；本次只修播放器与结构可视化组件。

## 业务规则与边界

1. 44px 是本项目播放器/移动交互的既定触控基线；按钮宽高差不得超过 1px。
2. 结构画布需要保持固定坐标时，只有外层轨道滚动；空态没有坐标内容，可使用容器宽度。
3. 桶列顺序和高亮状态不能因滚动或断点变化而改变。
4. 目标边界覆盖 320px、390px 竖屏和 770px/844px 横屏窄布局；页面 `scrollWidth` 不得超过视口。

## 验收口径

- `TC-PLAYER-142-01` 通过：三种窄屏视口下五个控件均为至少 44×44 且近似方形，速度框不超过 120px。
- `TC-VIZ-142-02` 通过：空队列画布完整落在轨道内并居中；入队后固定车道可在轨道内滚动到末端；页面无横溢出。
- `TC-VIZ-142-03` 通过：计数轨和桶轨所有桶列 top 相同，内部可滚动到末端，页面无横溢出。
- `TC-BUILD-142-04` 通过：production/selfhost 静态 HTML 不含 `127.0.0.1`、`localhost:4173` 等预览资源地址。
- 既有播放器、队列、计数排序、桶排序行为回归保持全绿。
